What to try

Start from P1. Reload its policy, then publish P2 and reuse cached P1: the transaction must be rejected without mutation. Revalidate, publish another rule before committing to expose the second race, and revert to P1 to see its original ETag return.

A 304 confirms only the selected HTTP representation. It does not authorize a later purchase. A 409 rejection and a wrong committed purchase are distinct outcomes.
